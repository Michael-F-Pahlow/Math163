    Subsection 13.1 Arclength

    In Math 152 (Calculus II) you learned howto calculate arc length for a function, \(y=f(x)\text{.}\) Except for a few carefully crafted examples, arc length in general is difficult to calculate due the square root in the integral from the Pythagorean theorem. With vector-valued functions, we can write a more general formula for arc length that is easily extended to three dimensions.
    🔗

    Arc Length Formulas.

    \begin{align*} \text{Math 152 Formula} \quad\amp \int_a^b \sqrt{1+f'(x)^2}dx \\ \text{2D Space} \quad \amp \int_a^b \sqrt{x'(t)^2+y'(t)^2}dt \\ \text{3D Space} \quad \amp \int_a^b \sqrt{x'(t)^2+y'(t)^2+z'(t)^2}dt\\ \text{where} \quad\amp \mathbf{r}(t)=\langle x(t),y(t),z(t)\rangle \end{align*}
    🔗
    🔗

    Example 13.1.

    Find the arc length of \(\langle 2(t-\sin(t)), 2(1-\cos(t))\rangle\) for \(0 \leq t \leq 2\pi\text{.}\)
    🔗
    Start by calculating the derivatives \(x'(t) = 2(1-\cos(t))\) and \(y'(t) = 2\sin(t)\) Then arc length is
    \begin{equation*} \int_0^{2\pi} \sqrt{(2(1-\cos(t)))^2+(2\sin(t))^2}dt =\\ \int_0^{2\pi} \sqrt{4-8\cos(t)+4\cos^2(t)+4\sin^2(t)}dt=\\ \int_0^{2\pi}\sqrt{8-8\cos(t)}dt = \\\int_0^{2\pi}\sqrt{16\sin^2(t/2)}dt =\\ \int_0^{2\pi}4\sin(t/2) dt = 16 \end{equation*}
    🔗
    🔗

    Example 13.2.

    Find the arc length of \(\langle 3t+5, 7t-6, -4t+9\rangle\) for \(0 \leq t \leq 5\text{.}\)
    🔗
    Start by calculating the derivatives \(x'(t) = 3\text{,}\) \(y'(t) = 7\) and \(z'(t) = -4\) Then arc length is
    \begin{equation*} \int_0^5 \sqrt{3^2+7^2+(-4)^2}dt = \int_0^5 \sqrt{74} dt = 5\sqrt{74} \end{equation*}
    🔗
    🔗
    Notice in this last example, that the space "curve" was just a straight line and that the arc length was just the length of the line from \(t=0\) to \(t=5\text{.}\) In terms of vectors, we calculate the magnitude of the linear vector. In fact we can define an arc length function for any space curve called the arc length parametrization:
    \begin{equation*} \text{arc length} \,\,\, = s(t) = \int_a^t ||\mathbf{r}'(u)|| du \end{equation*}
    🔗

    Example 13.3.

    Find the arc length parametrization of the circle of radius 4 defined by \(\mathbf{r}(t) = \langle 4\cos(t), 4\sin(t) \rangle\)
    \begin{equation*} s(t) = \int_0^t ||\langle -4\sin(u), 4\cos(u)\rangle|| du = \int_0^t\sqrt{16\sin^2(u)+16\cos^2(u)} du = \int_0^t 4du = 4t \end{equation*}
    This defines a relationship between arc length \(s\) and the original parameter \(t\text{.}\) If we take this to mean time, than one revolution of the circle which takes \(2\pi\) radians of time to traverse would have an arc length (circumference) of \(4\cdot2\pi = 8\pi\text{.}\)
    🔗
    🔗
    This arc length parametrization is key to defining the next application: curvature.
    🔗
    🔗

    Subsection 13.2 Curvature

    The curvature of a space curve is defined as
    \begin{equation*} \kappa = ||\mathbf{T}'(s)|| \end{equation*}
    where \(\mathbf{T}\) is the unit tangent vector and \(s\) is the arc length parametrization of the curve. Alternatively arc length can be calculated using the following formulas:
    \begin{align*} \text{in terms of}\,\, t\quad \amp \kappa = \frac{||\mathbf{T}'(t)||}{||\mathbf{r}'(t)||}\\ \text{for 3D curves} \quad \amp \kappa = \frac{||\mathbf{r}'(t)\times\mathbf{r}''(t)||}{||\mathbf{r}'(t)||^3}\\ \text{for} \,\,y = f(x) \quad \amp \kappa = \frac{|y''|}{[1+(y')^2]^{3/2}} \end{align*}

    Subsection 13.3 The T-N-B Frame

    We already know about the unit tangent vector, a vector with magnitude of one that points along the tangent line to a space curve. By definition, a unit vector and its derivative are orthogonal. We call this orthogonal unit vector the normal vector.
    \begin{equation*} \text{Unit Normal Vector}\,\,= \mathbf{N}(t) = \frac{\mathbf{T}'(t)}{||\mathbf{T}'(t)||} \end{equation*}
    We can then create a third unit vector that is orthogonal to both the unit tangent vector and the unit normal vector called the binormal vector by calculating a cross product.
    \begin{equation*} \text{Binormal Veector}\,\,=\mathbf{B}(t) = \mathbf{T}(t) \times \mathbf{N}(t) \end{equation*}
    Recall that order matters when you calculate the cross product. It’s always \(\mathbf{B} = \mathbf{T}\times\mathbf{N}\) and \(\mathbf{B} \ne \mathbf{N}\times\mathbf{T}\text{.}\)
    🔗
    These three vectors \(\mathbf{T}\text{,}\) \(\mathbf{N}\) and \(\mathbf{B}\) form a mini \(xyz\)-like axis that changes as you move along with the curve this is called T-N-B frame or Frenet frame. Play around with following GeoGebra demonstration by moving the slider for \(t\) and also trying out different functions.

    Subsection 13.4 Motion in Three-Dimensional Space

    For motion in space we are interest in position, velocity and acceleration. The relevant formulas are
    🔗

    Motion in Space.

    For a space curve \(\mathbf{r}(t)=\langle x(t), y(t),z(t)\rangle\)
    \begin{align*} \text{Velocity Vector}\quad \amp \mathbf{v}(t) = \mathbf{r}'(t) \\ \text{Speed}\quad \amp v(t) = ||\mathbf{v}(t)||\\ \text{Acceleration Vector}\quad \amp \mathbf{a}(t) = \mathbf{v}'(t) = \mathbf(r)''(t) \\ \text{Acceleration} \quad\amp \mathbf{a} = a_{\mathbf{T}}\mathbf{T} +a_{\mathbf{N}}\mathbf{N} \end{align*}
    The last formulas is a break down of the acceleration vector in terms of the unit tangent and normal vectors. \(a_{\mathbf{T}}=v'(t)\) and \(\kappa(t)v(t)^2 \text{.}\) Here is a video that explains more about that.
    🔗
    🔗

    Example 13.10.

    Find \(\mathbf{r}(t)\) given \(\mathbf{a}(t) = \langle e^t, 2t, t+1\rangle \text{,}\) \(\mathbf{v}(0) = \langle 1, 0 ,1\rangle\) and \(\mathbf{v}(0) = \langle 2, 1,1\rangle\) Here we need to integrate twice:
    \begin{equation*} \mathbf{v}(t)=\int \langle e^t, 2t, t+1\rangle dt = \langle e^t+c_1, t^2+c_2, \frac{1}{2}t^2+t+c_3\rangle \end{equation*}
    Plugging the values from the initial velocity vector gives
    \begin{equation*} \mathbf{v}(0) = \langle 1, 0 ,1\rangle = \langle e^0 + c_1, 0^2 + c_2, \frac{1}{2}0^2 + 0 + c_3 \rangle \to c_1 = 0, c_2 = 0, c_3 = 1 \end{equation*}
    Integrating this velocity function gives the position function
    \begin{equation*} \mathbf{r}(t)=\int \langle e^t, t^2, \frac{1}{2}t^2+t+1\rangle dt = \langle e^t+c_4, \frac{1}{3}t^3+c_5, \frac{1}{6}t^3+\frac{1}{2}t^2+t+c_6\rangle \end{equation*}
    Plugging the values from the initial position vector gives
    \begin{equation*} \mathbf{r}(0) = \langle 2, 1 ,1\rangle = \langle e^0 + c_3, \frac{1}{3}0^3 + c_5, \frac{1}{6}0^3 + \frac{1}{2}0^2+0 + c_6 \rangle \to c_4 = 1, c_5 = 1, c_3 = 1 \end{equation*}
    🔗
    \(\mathbf{r}(t) = \langle e^t + 1, \frac{1}{3}t^2 + 1, \frac{1}{6}t^3 + \frac{1}{2}t^2 + t + 1 \rangle \text{.}\)
