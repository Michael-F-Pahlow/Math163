    Section 15 Partial Derivatives

    For multi-variable functions, we need to take a derivative for each variable. These derivatives are called partial derivatives. Fortunately we already know all of the derivative rules from Math 151, so we move quickly through this section to applications in the next section.
    🔗

    Objectives: Partial Derivatives

    In this section we will look at:
    🔗
    • Notation for partial derivatives.
      🔗
      🔗
    • Higher-order and mixed partial derivatives.
      🔗
      🔗
    • The chain rule
      🔗
      🔗
    🔗

    Subsection 15.1 Notation

    Partial derivatives are denoted with "curly" d’s instead of straight d’s like ordinary derivatives. So the partial derivatives with respect to \(x\) and \(y\) are denoted as
    \begin{equation*} \frac{\partial f}{\partial x} \quad \text{and} \quad \frac{\partial f}{\partial y} \end{equation*}
    This is can challenging to write for those with less than neat handwriting and is also difficult to typeset. An alternative, easier notation is to use the a subscript for the derivatives.
    \begin{align*} \frac{\partial f}{\partial x}=\,\amp f_x(x,y)\\ \frac{\partial f}{\partial y}=\,\amp f_y(x,y) \end{align*}
    This subscript notation is also much easier for second or other higher-order derivatives.
    🔗
    When we take a partial derivative, we simply take the derivative for the given variable while treating the other variable as a constant.
    🔗

    Example 15.1.

    Consider the function \(f(x,y) = x^4 y + xy^{-2}\text{.}\) The partial derivatives are
    \begin{align*} f_x = \,\amp 4x^3 y + y^{-2} \\ f_y = \,\amp x^4 y -2xy^{-3} \end{align*}
    🔗
    🔗

    Example 15.2.

    Consider the function \(f(x,y) = \ln(x^2+y^2)\text{.}\) The partial derivatives are
    \begin{align*} f_x = \,\amp \frac{2x}{x^2+y^2} \\ f_y = \,\amp \frac{2y}{x^2+y^2} \end{align*}
    🔗
    🔗

    Example 15.3.

    Consider the function \(f(x,y) = y^2/(1+x^2)^3\text{.}\) The partial derivatives are
    \begin{align*} f_x = \,\amp \frac{-6xy^2}{(1+x^2)^4}\\ f_y = \,\amp \frac{2y}{(1+x^2)^3} \end{align*}
    🔗
    🔗

    Example 15.4.

    Consider the function \(f(x,y) = y^x\text{.}\) The partial derivatives are
    \begin{align*} f_x = \,\amp \ln(x)y^x \quad\text{exponential rule since x is the variable and y is a constant}\\ f_y = \,\amp xy^{x-1} \quad\text{power rule since y is the variable and x is a constant} \end{align*}
    🔗
    🔗
    🔗

    Subsection 15.2 Mixed Partial Derivatives

    Since we have two partial derivatives for a function with two input variables we can then calculate two derivatives from each of these derivatives. Using the subscript notation, we would write \(f_{xx}\) for the second partial derivative with respect to \(x\) and \(f_{xy}\) for the partial derivative first with respect to \(x\) and second with respect to \(y\text{.}\) Since we are mixing variables for this second derivative, this is called a mixed partial derivative.
    🔗

    Example 15.5.

    Consider the function \(f(x,y) = x^3+y^2 e^x\) Then the first and second order partial derivatives are:
    \begin{align*} f_x =\,\amp 3x^2+y^2 e^x\\ f_y =\,\amp 2ye^x\\ f_{xx} =\,\amp 6x+y^2 e^x\\ f_{xy} =\,\amp 2ye^x\\ f_{yy} =\,\amp 2e^x\\ f_{yx} =\,\amp 2ye^x \end{align*}
    Notice that the mixed partial derivatives are equal.
    🔗
    🔗
    Mixed partial derivatives are always equal. This is known as Clairaut’s Theorem. Not only does \(f_{xy}=f_{yx}\) but other higher-order mixed partials are also equal, so \(f_{xxxy} = f_{xxyx} = f_{xyxx} = f_{yxxx}\) (all of the mixed partials with one derivative with respect to \(y\) and three derivatives with respect to \(y\)).
    🔗

    Example 15.6.

    Calculate \(f_{yxx}\) for the function \(f(x,y) = \cos(x+y^2)\)
    🔗
    By Clairaut’s theorem, we can calculate two derivatives with respect to \(x\) and one derivative with respect to \(y\) in order. For this function, it is easier to calculate derivatives with respect to \(x\text{,}\) we will start there:
    \begin{align*} f_x= \amp -\sin(x+y^2)\\ f_{xx}= \amp -\cos(x+y^2)\\ f_{xxy}= \amp -2y\cos(x+y^2) = f_{yxx} \end{align*}
    🔗

    Subsection 15.3 The Chain Rule

    For the chain rule it is more convenient to use Leibniz (curly d) notation. For function \(f(x(t),y(t))\) where \(t\) is the "inside" variable. By the chain rule
    \begin{equation*} \frac{\partial f}{\partial t} = \frac{\partial f}{\partial x}\frac{\partial x}{\partial t} + \frac{\partial f}{\partial y}\frac{\partial y}{\partial t} \end{equation*}
    🔗

    Example 15.8.

    Calculate \(\frac{\partial f}{\partial t} \) for the function \(f(x,y) = 4x^2 + 3y^2\) where \(x(t) = \sin(t)\) and \(y(t) = \cos(t)\text{.}\) Start be calculating the derivatives with respect to \(x\) and \(y\text{.}\)
    \begin{align*} \frac{\partial f}{\partial x} =\,\amp f_x = 8x \\ \frac{\partial f}{\partial y} =\,\amp f_y = 6y \end{align*}
    Now calculate the derivatives with respect to \(t\text{.}\)
    \begin{align*} \frac{\partial x}{\partial t} =\,\amp\, \cos(t) \\ \frac{\partial y}{\partial t} =\,\amp -\sin(t) \end{align*}
    Plugging it all into the chain rule formula gives:
    \begin{equation*} \frac{\partial f}{\partial t} = \frac{\partial f}{\partial x}\frac{\partial x}{\partial t} + \frac{\partial f}{\partial y}\frac{\partial y}{\partial t} \end{equation*}
    \begin{equation*} = (8x)(\cos(t))+ (6y)(-\sin(t)) = 8(\sin(t))(\cos(t))-6(\cos(t))(\sin(t)) = 2\sin(t)\cos(t) \end{equation*}
    🔗
    🔗
    For inside functions of two-variables the chain rule for \(z=f(x(u,v),y(u,v))\) is
    \begin{equation*} \frac{\partial f}{\partial u} = \frac{\partial z}{\partial x}\frac{\partial x}{\partial u} + \frac{\partial z}{\partial y}\frac{\partial y}{\partial u} \end{equation*}
    and
    \begin{equation*} \frac{\partial f}{\partial v} = \frac{\partial z}{\partial x}\frac{\partial x}{\partial v} + \frac{\partial z}{\partial y}\frac{\partial y}{\partial v} \end{equation*}
