    Subsection 16.1 Tangent Planes

    Similar to a tangent line in two-dimensions, we can form a tangent plane in three-dimensions (or a hyperplane in higher dimensions). The equation of a tangent plane at the point \((x,y)=(a,b)\)is
    \begin{equation*} L(x,y) = f(a,b) + f_x(a,b)(x-a) + f_y(a,b)(y-b) \end{equation*}
    🔗

    Example 16.1.

    Find the plane tangent to \(f(x,y) = x^2 y+ xy^3\) at the point (2, 1). Start by calculating the partial derivatives
    \begin{align*} f_x = \, \amp 2xy + y^3\\ f_y = \, \amp x^2 + 3xy^2 \end{align*}
    Plug the point into the original function and partial derivatives.
    \begin{align*} f(2,1) = \, \amp 4 + 2 = 6\\ f_x(2,1) = \, \amp 4 + 1 = 5\\ f_y(2,1) = \, \amp 4 + 6 = 10 \end{align*}
    Plugging it all into the tangent plane formula and get
    \begin{equation*} L(x,y) = 6 + 5(x-2) + 10(y-1) \end{equation*}

    Subsection 16.2 Linear Approximation

    The tangent plane also defines a linear approximation (or first-degree Taylor approximation) of \(f(x,y)\) at a given point.
    🔗

    Example 16.3.

    Estimate \((2.01)^3(1.02)^2\) using a linear approximation. We can define a function \(f(x,y)=x^3 y^2\text{.}\) \(f(2,3) = 2^3 1^2 = 8\) is easily calculated, so we will use the point (2,3). The linear approximation, calculated in the same steps as the last example, is:
    \begin{align*} f_x = \, \amp 3x^2 y^2\\ f_y = \, \amp 2x^3 y\\ f(2,1) = \, \amp 8\\ f_x(2,1) = \, \amp 12\\ f_y(2,1) = \,\amp 16\\ L(x,y) = \, \amp 8 + 12(x-2) + 16(y-1) \end{align*}
    Plugging (2.01, 1.02) into the linear approximation gives
    \begin{equation*} (2.01)^3(1.02)^2 \approx L(2.01, 1.02) = 8 + 12(2.01-2)+16(1.02-1) = 8.44 \end{equation*}
    \((2.01)^3(1.02)^2 = 8.44867328\text{,}\) so our approximation matches the first two decimal places.
    🔗
    🔗

    Example 16.4.

    Let \(B=W/H^2\) defines a person’s body mass index (BMI), where \(W\) is a person’s weight in kilograms and \(H\) is a person’s height in meters. Find the approximate BMI for a person weighs 89.7 kilograms and is 1.98 kilometers (198 centimeters) tall. The point \((W,H) = (90,2)\) gives a BMI of \(B = 22.5\text{.}\) Calculating the derivatives and writing out the linear approximation gives:
    \begin{align*} B_W=\, \amp \frac{1}{H^2}\\ B_H=\, \amp -\frac{2W}{H^3}\\ B(90,2)=\, \amp 22.5\\ B_W(90,2)=\, \amp 0.25\\ B_H(90,2)=\, \amp -22.5\\ L(H,W)=\, \amp 22.5 + 0.25(W-90)-22.5(H-2) \end{align*}
    So \(B(89.7,1.98) \approx L(89.7,1.98) = 22.5 + 0.25(89.7-90)-22.5(1.98-2) = 22.9425\)

    Subsection 16.3 The Directional Derivative and Gradient Vector

    A directional derivative, is a partial derivative that points along the vector \(\mathbf{u}\text{.}\) Note that \(\mathbf{u}\) is a vector. Recall that a vector has a magnitude (which equals 1 for the directional derivative) and direction and that to write a vector in component form given the vector’s direction and magnitude, you get \(\langle \cos(\theta), \cos(\theta)\rangle\text{.}\) We will do something similar for the directional derivative where the partial derivatives play the role of the magnitude. The directional derivative along the unit vector \(\mathbf{u}\) with direction \(\theta\) is:
    \begin{equation*} D_{\mathbf{v}}f(x,y) = f_x(x,y)\cos(\theta) + f_y(x,y)\sin(\theta) \end{equation*}
    🔗

    Example 16.6.

    Find the directional derivative of \(f(x,y) = x^2+2y^2\) in the direction \(\theta = \frac{\pi}{4}\text{.}\)
    🔗
    Calculate the partial derivatives
    \begin{align*} f_x =\, \amp 2x\\ f_y =\, \amp 4y \end{align*}
    Then the directional derivative is: \(D_{\mathbf{v}}f = \frac{\sqrt{2}}{2}2x+\frac{\sqrt{2}}{2}4y = \sqrt{2}x+2\sqrt{2}y\)
    🔗
    🔗

    Example 16.7.

    Find the directional derivative of \(f(x,y) = e^x\sin(y)\) along the vector \(\langle \frac{1}{2},\frac{\sqrt{3}}{2}\rangle\text{.}\)
    🔗
    Calculate the partial derivatives
    \begin{align*} f_x =\, \amp e^x\sin(y)\\ f_y =\, \amp e^x\cos(y) \end{align*}
    Next find the direction of the vector
    \begin{equation*} \theta = \arctan\left(\frac{1}{2}\cdot\frac{2}{\sqrt{3}}\right) = \frac{\pi}{3} \end{equation*}
    Then the directional derivative is:
    \begin{equation*} D_{\mathbf{v}}f = \frac{1}{2}e^x\sin(y)+\frac{\sqrt{3}}{2}e^x\cos(y) \end{equation*}
    🔗
    🔗
    Another way to define the directional derivative is using the gradient, The gradient vector is defined as \(\nabla f(x,y) = \langle f_x,f_y \rangle\text{.}\) \(\nabla f\) is read as "del f". Del and the gradient will be used often in Calculus IV. The directional derivative may also be defined using the gradient as \(D_\mathbf{u}f(x,y) = \nabla f(x,y)\cdot\mathbf{u}\text{.}\)
    🔗
    The gradient may also be used to find a plane tangent to a surface. Given a surface defined by an equation \(F(x,y,z)=k\) where \(k\) is a constant, then the tangent plane at point \(p = (a,b,c)\) is \(\nabla F \cdot \langle x-a, y-b, z-c \rangle = 0\text{.}\) For a function \(z=f(x,y)\) we can rewrite this as \(F(x,y,z) = f(x,y)-z = 0\text{.}\) The dot product here produces the same formula for the tangent plane given earlier.

    Subsection 16.4 The Second Derivative Test

    Finally, one of the most important applications is optimization; finding a maximum and minimum. In Calculus I (Math 151) we saw three ways to optimize a function using derivatives: the Extreme Value Theorem, the First Derivative Test and the Second Derivative Test. There is a multi-variable analog to the Extreme Value Theorem, called Lagrange multipliers that we will look at it in the next section. Recall that the First Derivative Test looks at what happens to the sign (positive or negative) of a derivative around a critical value as you move along number line from left to right. Since we can move from left to right (along the \(x\)-axis) along different \(y-\)lines in three dimensions, this would produce an infinite amount of results, so the First Derivative does not work in higher dimensions.
    🔗
    The Second Derivative Test, which use concavity to find local maximum and minimum values, does work in three dimensions. Similar to the single-variable version of the Second Derivative Test, we first find critical points and then plug them into the second derivative to test their concavity. Critical points in three dimensions are defined as points where:
    \begin{align*} f_x(a,b) = 0 \,\,\,\text{or}\,\,\,\amp f_x(a,b) \,\,\,\text{does not exist, and}\\ f_y(a,b) = 0 \,\,\,\text{or}\,\,\,\amp f_y(a,b) \,\,\,\text{does not exist.} \end{align*}
    At a critical value, if the three-dimensional surface, is concave up in all directions, then you are at a local minimum and if the surface is concave down in all directions, then you are at a local maximum. If you are concave up in some directions but concave down in other directions, then you are at a saddle point. Since there are both mixed, second partial derivatives and second partial derivatives of a single variable, we also define the discriminant for the second derivatives to tell us the concavity at a point as:
    \begin{equation*} D(a,b) = f_{xx}(a,b)\cdot f_{yy}(a,b) - f_{xy}^2(a,b) \end{equation*}
    Then the Second Derivative Test is:
    🔗

    Second Derivative Test.

    Let \(P=(a,b)\) be a critical point of \(f(x,y)\) and \(D\) be the discriminant of \(f(x,y)\text{,}\) then if:
    \begin{align*} D\gt 0 \,\,\amp\text{and}\,\, f_{xx}(a,b)\gt 0, \,\,\text{then}\,\, f(a,b) \,\,\text{is a local minimum.} \\ D\gt 0 \,\,\amp\text{and}\,\, f_{xx}(a,b)\lt 0, \,\,\text{then}\,\, f(a,b) \,\,\text{is a local maximum.} \\ D\lt 0, \,\,\amp\text{then}\,\, f(a,b) \,\,\text{is a saddle point.} \\ D = 0, \,\,\amp\text{then the test is inconclusive.} \end{align*}
    🔗
    🔗

    Example 16.9.

    Find and classify the critical points for the function \(f(x,y)=x^3+y^3-12xy\text{.}\)
    🔗
    Start by taking te partial derivatives:
    \begin{align*} f_x =\, \amp 3x^2-12y\\ f_y =\, \amp 3y^2-12x\\ f_{xx} =\, \amp 6x\\ f_{yy} =\, \amp 6y\\ f_{xy} =\, \amp -12y \end{align*}
    Next find the critical points. (This is usually the most work for these problems.)
    \begin{equation*} f_x = 0\, =3x^2-1y \quad\to\quad y = \frac{1}{4}x^2 \end{equation*}
    \begin{equation*} f_y = 0\, =3x^2-1y \,\,\,\text{plug the first equation into this second equation to get} \end{equation*}
    \begin{equation*} 3(x^2/4)^2 - 12x = \frac{3}{16}(x^3-64) \,\,\to\,\, x = 0, 4 \end{equation*}
    \begin{equation*} \text{plugging these x-values into the first equation to get the critical points} \end{equation*}
    \begin{equation*} (0,0)\,\,\text{and}\,\,(4,4) \end{equation*}
    Plug these into the discriminant and second derivative to get
    \begin{align*} D(0,0) = -144 \lt 0\quad \amp \text{saddle point at (0,0)} \\ D(4,4) = 432 \gt 0\,\,\text{and}\,\, f_{xx} = 24 \gt 0\quad \amp \text{local minimum at (4,4)} \end{align*}
    Try plotting this surface to verify the solutions.
    🔗
    🔗

    Example 16.10.

    Find and classify the critical points for the function \(f(x,y)=4x^2+9y^2+8x-36y+24\text{.}\)
    🔗
    Start by taking te partial derivatives:
    \begin{align*} f_x =\, \amp 8x+8\\ f_y =\, \amp 18y-36\\ f_{xx} =\, \amp 8\\ f_{yy} =\, \amp 0\\ f_{xy} =\, \amp 18 \end{align*}
    Next find the critical points.
    \begin{equation*} 8x+8=0 \quad \to \quad x = -1 \end{equation*}
    \begin{equation*} 18y-36=0 \quad \to \quad y=2 \end{equation*}
    The only critical point is (-1,2) Plug this into the discriminant and second derivative to get
    \begin{equation*} D(-1,2) = 144 \gt 0 \,\,\text{and}\,\, f_{xx} = 8 \gt 0 \end{equation*}
    So (-1, 2) is a local minimum.
    🔗
    🔗

    Example 16.11.

    A shipping company handles rectangular boxes provided the sum of the length, width, and height of the box does not exceed 96 inches. Find the dimensions of the box that meets this condition and has the largest volume.
    🔗
    Define two equations based on the given information.
    \begin{equation*} l+w+h = 96 \quad \text{and} \quad V=lwh \end{equation*}
    Solve the first equation for one of the variables and plug the result into the second equation, eliminating one of the variables. I will eliminate \(h\text{.}\)
    \begin{equation*} h= 96-l-w \quad \to \quad V=lw(96-l-w) = 96lw - l^2w-lw^2 \end{equation*}
    This is the equation we will maximize.
    \begin{align*} V_l =\, \amp 96w - 2lw - w^2\\ V_w =\, \amp 96l - l^2 - 2lw\\ V_{ll} = \, \amp -2w \\ V_{ww} = \, \amp -2l \\ V_{lw} = \, \amp 96 - 2l -2w \end{align*}
    Find the critical values
    \begin{align*} 96w-2lw-w^2 = 0 \quad\amp \to w(96-2l-w)=0\\ 96l-l^2-2lw = 0 \quad\amp \to l(96-2w-l)=0 \end{align*}
    Which gives one critical point at (0,0). Solve \(96-2l-w = 0 \) for \(w\) and plug it into the second for the second equation to get
    \begin{equation*} 96 - 2(96-2l)-l = 0 \quad \to \quad -96 +3l = 0 \quad \to \quad l = 32 \end{equation*}
    Which when substituted back in the first equation gives \(w=32\) and we get a second critical point at (32,32). The critical point at (0, 0) gives a volume of zero, which in the context of the problem is the minimum possible volume. \(D(32,32) = -2(32)(-2)(32)-(-32)^2 = 3072 \gt 0\) and \(V_{ll}(32,32) = -64 \lt 0\) and (32, 32) is at a local maximum. The maximum volume occurs when \(l=w=h=32\) for a maximum volume of \(V=32^3 = 32,768\) cubic inches.
