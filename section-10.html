    Section 10 Object in Three-Dimensional Space

There are multiple ways to represent an object in three-dimensional space and depending on what you want to calculate, one of these ways is usually easier than the others.     Subsection 10.1 Multi-variable Functions

    We are used to writing functions \(y=f(x)\) for writing functions in two dimensions and maybe even are used to writing equations like \(x^2+y^2 = 1\) in two dimensions. Extending this idea to three dimensions we can write functions like \(z=f(x,y)\) or \(x^2+y^2+z^2=1\text{.}\) Here are a few common functions.
    🔗

    Example 10.1. Planes.

    A plane can be written as a function: \(f(x,y) = ax+by+c\) where \(a, b\) and \(c\) are constants or as an implicit equation: \(ax+by+cz=d\text{.}\) Like the slope of a line and intercepts, the constants control the "tilt" of the plane and the intercepts. Here is a plot of the plane: \(z = x-\frac{1}{3}y+5\)
    🔗
    🔗

    Example 10.3. Cylinders.

    A cylinder is simply a circle extended in a third dimension. The equation \(x^2+y^2 = r^2\) would describe a circle on the \(xy\)-plane and but in three dimensions this circle would extend infinitely in the \(z\)-direction to form a cylinder. Here is a plot of the cylinder \(x^2+y^2=4\)
    🔗
    🔗

    Example 10.5. Spheres.

    The equation of a sphere is similar to the equation of a circle \(x^2+y^2+z^2=r^2\text{.}\) Here is a plot of the sphere \(x^2+y^2+z^2=4\)
    🔗
    🔗
    Write three dimensional shapes using the familiar function notation or equations with the variables \(x, y\) and \(z\) works well when the shapes have flat sides or are defined by functions like exponentials, logarithms or powers. But for some shapes it is easier to change to a coordinate system that fits the shape.
    🔗
    🔗

    Subsection 10.2 Alternative Coordinate Systems

    The variables \(x, y\) and \(z\) define a grid made of cubes where a point like (5, 1, -4) means start at the origin and move for squares in the positive \(x\) direction, one sqaure in the positive \(y\) direction and down 4 squares in he \(z\)direction. This coordinate system is called the Cartesian coordinaes system (after Rene DeCarte) or the rectangular coordinate system since the origin and a given point would be opposite corners of a recatangle. There are two other common coordinate systems that we use: one defined by cyclinders and one defined by spheres.
    🔗

    Cylindircal Coordinates.

    This coordinate system is formed by circles in the \(xy\)-plane (polar coordinates) and keeping \(z\) as the third dimension. To convert between the Cartesian coordinate system \((x,y,z)\) and cylindrical coordinates \((r,\theta,z)\)
    🔗
    Polar to Cartesian
    \begin{align*} x= \amp r\cos(\theta)\\ y= \amp r\sin(\theta)\\ z = \amp z \end{align*}
    🔗
    Cartesian to Polar
    \begin{align*} r=\amp \sqrt{x^2+y^2} \\ \theta = \amp \arctan(y/x) \\ z= \amp z \end{align*}
    🔗
    🔗
    In cyclindircal coordinates a cylinder is defiend as \(r=\)consant and a sphere is defined as \(r^2+z^2=c^2\text{.}\) Another coordinate system is defined be a series of concentric spheres.
    🔗

    Spherical Coordinates.

    Spherical coordinates are defined by two angles. One angle going around the \(z-\)axis is \(\theta\) which is the same \(\theta\) in cylindiral and polar coordinates. A second angle is defined as the angle between the \(z-\)axis and a radius vector. This angle is \(\phi\text{.}\) The third coordinate is the radius which extends from the radius to a point on the sphere and is called \(\rho\) which looks like a "p" but is pronounced rho and makes the "r"-sound in Greek.
    🔗
    Spherical to Cartesian
    \begin{align*} x=\amp \rho\sin(\phi)\cos(\theta) \\ y=\amp \rho\sin(\phi)\sin(\theta) \\ z=\amp \rho\cos(\phi) \end{align*}
    🔗
    Cartesian to Spherical
    \begin{align*} \amp \end{align*}
    \begin{align*} \rho=\amp \sqrt{x^2+y^2+z^2} \\ \theta =\amp \arctan(y/x)\\ \phi =\amp \arccos\left(\frac{z}{\sqrt{x^2+y^2+z^2}}\right) \end{align*}
    🔗
    🔗
    In spherical coordinates a sphere is simply defiend as \(\rho=\)constant.
    🔗
    🔗

    Subsection 10.3 Sets of Parametric Equations

    Another way to define an object in three-dimensional space is by using a set of parametric equations. This defines a space curve. For parametric equations we first define a parameter, usually \(t\) for time. As an example the set of parametric equations:
    \begin{equation*} \begin{cases} x(t) = \cos(t) \amp\\ y(t) = \sin(t) \amp\\ z(t)=0.1t \amp\\ \end{cases} \end{equation*}
    draws a helix.
    🔗
    More on parametric equations in future sections.
    🔗
    🔗

    Subsection 10.4 Vector-Valued Functions

    A vector-valued function is simply a set of parametric equations written as the components of a vector. Such as \(\mathbf{r}(t) =\langle t^2, t+5, -4t^3\text{.}\) Evaluating this function at a value for \(t\) creates a vector: \(\mathbf{r}(2) = \langle 1, 6, -4 \rangle\text{.}\) If we take \(t\) to be time then \(\mathbf{r}(t)\) would be a position vector. Vector-valued functions are very useful in calculus to define things like velocity and acceleration vectors and tangent vectors. We will explore this in the next few sections.
